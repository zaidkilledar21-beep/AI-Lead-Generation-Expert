01 / Visual Principles

Make synchronization feel expensive, not flashy.

The brand should avoid the usual AI automation tropes. The design language is controlled, architectural, and systems-oriented: premium copy, precise grids, dark operating visuals, and honest process credibility.

Synchronization, not spectacle

Motion resolves scattered nodes into connected paths. It should communicate clarity, not entertainment.

Infrastructure investment

Language frames the work as reusable operating infrastructure: cleaner handoffs, safer decisions, better visibility.

Proof through process

Credibility comes from founder-built systems, representative examples, tool fluency, and a serious implementation approach.

02 / Color System

Dark navy base, indigo control layer, blue data movement.

Green, amber, and red are reserved for state. Purple and blue carry brand energy but should never become a generic AI glow.

03 / Component System

Components should feel like parts of an operating layer.

Cards, forms, diagrams, founder bios, and CTAs should all share one language: crisp hierarchy, honest labels, bounded density, and precise state indicators.

Service cards

Workflow Automation, AI Agents, Reporting Dashboards, and Internal Ops Systems. Each should state one operational outcome and show capability chips.

Diagram panels

Use labels like "Representative automation map" and "Internal operating system concept" so mockups never imply fake client work.

Assessment form

Make the CTA feel like the first step in a serious infrastructure review, not a generic lead capture form.

04 / Homepage Rhythm

06 / Three Concepts

One locked direction, three execution postures.

All three concepts use the same Synqro brand system. The difference is how much the homepage leads with consultancy trust versus technical system proof.

Concept A

Premium Consultancy First

Hero layout
Editorial left-aligned hero with a restrained assessment-preview visual.
Hero visual
Automation assessment preview with a small workflow map behind it.
Section rhythm
More light sections early: problem, process, trust, founders.
Mockup style
Clean tables, capability cards, founder credentials, subtle diagrams.
Animation style
Slow fade, path draw, minimal diagram motion.
Strength
Most premium and safest for senior buyers.
Risk
May under-signal hands-on technical build capability.
Concept B

Technical Automation Studio First

Hero layout
Full dark command center with the workflow diagram taking half the viewport.
Hero visual
Source cards animate into AI decision, approval, CRM, and reporting outputs.
Section rhythm
Dark technical sections dominate, with UI evidence throughout.
Mockup style
Workflow lanes, node diagrams, dashboard fragments, status chips.
Animation style
Visible sync paths, node pulses, checkpoint highlights.
Strength
Strongest proof that Synqro can build.
Risk
Can drift into developer-tool territory if copy is not consultative.
Concept C

Balanced Premium Systems Studio

Hero layout
Premium two-column hero where copy leads and the diagram proves the concept.
Hero visual
Before/after workflow transformation into a connected operating layer.
Section rhythm
Dark hero, light problem, dark AI/process, light services, dark examples, light trust.
Mockup style
Operating maps, assessment tables, system cards, founder credibility blocks.
Animation style
Controlled path synchronization, subtle reveal, small card lift.
Strength
Best balance of premium trust and technical seriousness.
Risk
Requires discipline so diagram detail does not reduce elegance.
Recommended Final Concept

Choose Concept C: Balanced Premium Systems Studio.

Concept C makes Synqro feel expensive and credible while still showing that the founders can design and build the technical operating layer underneath. Concept A risks becoming too abstract. Concept B risks feeling too much like a developer product.
