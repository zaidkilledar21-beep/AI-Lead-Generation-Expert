# Design Systems Index

This folder contains selected Open Design design-system references copied into the repo for Codex/Open Design planning and implementation.

Use these references only as inspiration and constraints. Do not blindly copy layouts or create a parallel component system.

## Selected References

### Linear
Use for:
- workflow clarity
- pipeline/task states
- compact productivity UI
- review queues
- status-heavy interfaces

Best CRM areas:
- Pipeline
- Review Queue
- Lead lifecycle
- Inbox status handling

### Stripe
Use for:
- trustworthy SaaS hierarchy
- forms
- settings
- analytics
- empty states
- enterprise polish

Best CRM areas:
- Campaign forms
- Settings
- Analytics
- Empty states
- Diagnostics

### Vercel
Use for:
- minimal dark UI
- clean shell
- developer-tool polish
- restrained visual hierarchy

Best CRM areas:
- Global shell
- Navigation
- Page headers
- Loading/error states


### Magic UI
Use sparingly for:
- microinteractions
- loading states
- small visual delight
- transition polish

Avoid:
- excessive animation
- flashy landing-page effects
- anything that weakens operational readability
